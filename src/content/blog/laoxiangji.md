# 一、招牌鸡汤系列（门店核心爆款）
1. 老乡鸡经典老母鸡汤
菜品特点：汤色清亮金黄、鸡油醇厚、肉质鲜嫩不柴、无重香料、原汁原味，是品牌招牌核心菜品。
食材准备（家庭2-3人份）
- 主料：老母鸡半只/三黄鸡1000g
- 辅料：生姜20g、大葱1段、枸杞少许
- 调味：食盐适量、白胡椒粉少许（无其他复杂调料）
制作步骤
1. 鸡肉切块，冷水浸泡20分钟去血水，冷水下锅加姜片、料酒焯水，煮沸撇净浮沫，捞出温水洗净沥干。
2. 砂锅加足量清水，放入鸡块、姜片、葱段，大火烧开后全程最小火慢炖90分钟。
3. 炖至汤色金黄、肉质酥烂，挑出葱姜，加适量盐、少许白胡椒粉调味。
4. 最后放入枸杞焖3分钟即可，无需加味精、鸡精，保留鸡汤本味。
门店复刻关键：全程小火微沸不翻滚，盐最后放，避免肉质发柴、汤色浑浊。
2. 笋子鸡汤
菜品特点：鸡汤鲜醇，笋片脆嫩解腻，荤素搭配清爽不厚重。
食材：老母鸡汤底、新鲜春笋/冬笋、姜片、盐、白胡椒粉
做法：鸡汤炖至8成熟时，放入焯水去涩的笋片，小火继续炖20分钟，加盐、白胡椒粉调味即可。
# 二、烧鸡/鸡肉招牌系列（门店Top爆款）
1. 经典毛豆烧鸡
菜品特点：浓油赤酱、鸡肉入味、毛豆软糯，汤汁拌饭一绝，门店销量榜首。
食材准备
- 主料：土鸡块600g、新鲜毛豆300g
- 辅料：姜、蒜、干辣椒少许、葱段
- 调味：生抽、老抽、料酒、冰糖、盐、少许蚝油
制作步骤
1. 鸡块焯水去血沫，沥干备用；毛豆清水焯水煮2分钟去生味。
2. 热锅少油，下姜蒜、干辣椒爆香，放入鸡块中火煸炒至表面微黄收紧。
3. 烹入料酒去腥，加生抽提鲜、老抽上色、少许冰糖炒出糖色，翻炒均匀。
4. 加入没过食材的开水，大火烧开转中火焖煮25分钟。
5. 放入毛豆，加盐、少许蚝油调味，继续焖10分钟，大火收浓汤汁即可。
2. 招牌葱油鸡
菜品特点：清蒸锁鲜、皮爽肉嫩、葱香浓郁，清淡低脂、原汁原味。
食材：三黄鸡1只、大葱、小葱、生姜、生抽、蒸鱼豉油、食用油
做法
1. 整鸡处理干净，冷水下锅加葱姜、料酒，小火浸煮15分钟，关火焖20分钟至熟透。
2. 捞出过冰水，鸡皮紧致Q弹，切块装盘。
3. 碗中调葱油汁：葱花+姜丝+生抽+蒸鱼豉油，浇上滚烫热油激出香味，淋在鸡肉上即可。
3. 香辣鸡杂
菜品特点：鸡杂Q弹爽脆、香辣入味、下饭神器，不腥不柴。
食材：鸡胗、鸡心、鸡肝、泡椒、小米辣、姜蒜、葱段、生抽、料酒、豆瓣酱、盐、白糖
做法
1. 鸡杂切薄片，加料酒、盐抓洗去腥，焯水10秒迅速捞出，控干水分。
2. 热锅热油，爆香姜蒜、泡椒、豆瓣酱，炒出红油。
3. 下入鸡杂大火快速翻炒30秒，加生抽、少许白糖提鲜。
4. 放入葱段、小米辣翻炒均匀，关火出锅，全程大火快炒保脆嫩。
4. 三杯鸡
菜品特点：一杯酱油、一杯米酒、一杯香油，肉嫩汁浓、酱香醇厚、咸甜适口。
食材：鸡腿块500g、姜蒜、九层塔/葱花、生抽、米酒、香油、冰糖
做法
1. 鸡腿块焯水沥干，无油干锅煸炒出鸡油。
2. 加姜蒜爆香，依次加入等量米酒、生抽、少许老抽、冰糖。
3. 小火焖煮20分钟，大火收汁，淋入香油，撒葱花即可。
# 三、招牌蒸菜系列（低脂健康、门店必点）
1. 农家蒸蛋
菜品特点：嫩滑无蜂窝、入口即化、老少皆宜。
配比：鸡蛋2个、温水1.5倍、少许盐、葱花、生抽、香油
做法：鸡蛋加温水、盐搅匀，过筛撇去浮沫，水开上锅中小火蒸8分钟，焖2分钟，淋生抽、香油、撒葱花。
2. 梅菜扣肉
菜品特点：肥而不腻、软烂入味、梅菜吸满肉香，门店经典蒸硬菜。
食材：五花肉、梅干菜、姜蒜、生抽、老抽、蚝油、白糖、料酒
做法
1. 五花肉煮熟，表皮抹老抽、白糖，下锅炸至表皮红亮起泡。
2. 切片摆盘，泡发洗净的梅干菜铺在肉上。
3. 调酱汁：生抽+老抽+蚝油+白糖+料酒+清水，淋入盘中。
4. 上锅大火蒸40分钟，倒扣装盘即可。
3. 粉蒸肉
菜品特点：米粉软糯、肉质酥烂、咸香微甜，不油不腻。
食材：肥瘦相间五花肉、蒸肉米粉、生抽、老抽、料酒、白糖、豆瓣酱
做法：五花肉切片，加所有调料腌制30分钟，均匀裹上蒸肉米粉，铺盘大火蒸50分钟即可。
4. 番茄菌菇肉丸
菜品特点：肉丸Q弹、汤底鲜甜、清淡养胃。
食材：猪肉马蹄肉丸、番茄、金针菇、香菇、盐、少许生抽
做法：番茄炒出沙，加清水煮开，下入菌菇、肉丸，煮至浮起，加盐调味即可。
# 四、热销小炒硬菜系列
1. 农家小炒肉
食材：五花肉/瘦肉、青椒、蒜、干辣椒、生抽、老抽、料酒、盐、鸡精
做法：肉片煸炒出油，爆香配料，下青椒大火翻炒，调味断生即可，鲜香下饭。
2. 宫保鸡丁
食材：鸡胸肉、花生米、黄瓜丁、胡萝卜丁、葱姜蒜、干辣椒
料汁：生抽+陈醋+白糖+少许老抽+淀粉+清水
做法：鸡丁滑炒变色，下入配菜翻炒，淋入料汁大火收汁，最后放花生米出锅。
3. 金汤酸菜鱼
菜品特点：酸辣开胃、鱼片滑嫩、汤浓味足。
食材：黑鱼片、酸菜、金汤酱、姜片、葱花、白芝麻
做法：酸菜炒干炒香，加水/高汤煮开，下入腌制好的鱼片，煮至变色熟透，淋热油激香即可。
4. 鸡汁辣鱼
菜品特点：徽州风味、酱香浓郁、微辣入味。
做法：鱼肉煎至定型，加入鸡汁汤底、秘制辣酱焖煮入味，收汁入味即可。
# 五、清淡素菜系列
1. 白菜炖豆腐
食材：大白菜、嫩豆腐、葱花、盐、生抽、少许猪油
做法：猪油炒软白菜，加清水煮开，下豆腐焖煮8分钟，加盐、生抽调味，汤汁鲜美。
2. 莴笋丝炒鸡蛋
做法：鸡蛋炒熟盛出，莴笋丝清炒断生，混合鸡蛋加盐调味，清爽解腻。
3. 芹菜炒香干
做法：香干煎至微焦，下入芹菜大火快炒，加盐、生抽调味，家常清淡小炒。
4. 小炒脆笋
做法：脆笋焯水去涩，蒜末爆香，大火快炒，少许盐、生抽调味，脆嫩爽口。
# 六、主食&汤粥小吃系列
1. 鸡丝沙汤
食材：熟鸡丝、木耳丝、蛋皮丝、淀粉水、胡椒粉、香油、盐
做法：清水烧开，下入配菜，淀粉水勾芡浓稠，淋入蛋液，调味后撒鸡丝、淋香油、白胡椒粉即可。
2. 阳春面
汤底：葱花、盐、生抽、少许猪油、鸡汤底
做法：面条煮熟，冲入调好的鸡汤汤底，简单鲜香，还原门店原味。
3. 香辣牛肉面
做法：牛肉卤制软烂，熬制香辣汤底，面条煮熟，加入牛肉、配菜、汤底即可。
4. Q弹虾滑馄饨
做法：鲜虾馅包入馄饨皮，鸡汤底煮熟，鲜美弹牙，清淡适口。
# 七、老乡鸡通用复刻核心技巧（门店标准）
1. 主打本味：绝大多数菜品少油少重料，依托鸡汤底提鲜，不依赖重香料，突出家常鲜香。
2. 火候关键：鸡汤、蒸菜全程小火慢焖慢蒸；小炒、鸡杂全程大火快炒，保证口感。
3. 调味原则：咸淡适中、鲜而不腻，糖仅用于提鲜上色，不做甜口主打。
4. 口感标准：炖菜软烂入味、蒸菜嫩滑锁水、小炒脆嫩爽口、卤烧浓醇下饭。
